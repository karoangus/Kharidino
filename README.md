# خریدینو (Kharidino) 🛒

> **خریدت رو ساده کن.**

خریدینو یک وب‌اپلیکیشن قابل‌نصب (PWA) برای مدیریت لیست خرید است: فارسی، راست‌به‌چپ، موبایل‌فرست و **کاملاً آفلاین**. تمام داده‌ها فقط روی دستگاه خودت ذخیره می‌شود.

---

## امکانات

- **لیست‌های خرید** با نام و نماد، تعداد کالاها، درصد پیشرفت، تاریخ آخرین تغییر + تغییر نام و حذف (با تأیید)
- **افزودن سریع ⚡** — وارد لیست شو، «+» بزن، کالا را لمس کن؛ همین. کالاهای تکراری به‌جای ردیف جدید، تعدادشان جمع می‌شود
- **جست‌وجوی سریع 🔎** روی کالاهای پیش‌فرض + کالاهای شخصی + کالاهای من (با تطبیق ی/ي، ک/ك و نیم‌فاصله)
- **پیشنهادهای سریع** بالای صفحهٔ افزودن: کالاهای همین لیست + پرمصرف‌ها + کالاهای من
- **کالاهای من ⭐** — کالاهای پرمصرف با پیش‌فرض شخصی (تعداد، واحد، قیمت، یادداشت)؛ با یک لمس به هر لیستی اضافه می‌شوند
- **۹ دسته‌بندی آماده** (سوپرمارکت، میوه و سبزیجات، پروتئینی، نوشیدنی، تنقلات، بهداشتی، شوینده و خانه، فریزی، حیوانات خانگی) + امکان افزودن **کالای شخصی** به فهرست
- **تعداد، واحد، قیمت (تومان) و یادداشت** برای هر کالا — استپر «− عدد +» و امکان ورود مستقیم عدد
- **حالت خرید** — تیک یک‌لمسه‌ای، خط‌خوردگی و کم‌رنگ‌شدن، نوار پیشرفت «۸ از ۱۲ کالا خریداری شده»
- **مجموع تقریبی 💰** با ارقام فارسی؛ اگر بعضی کالاها قیمت نداشته باشند، مجموع فقط بر اساس کالاهای دارای قیمت محاسبه شده و برنامه آن را واضح نشان می‌دهد (قیمت‌ها تخمینی‌اند)
- **۴ تم** — ☀️ روشن، 🌙 تاریک، 💜 نئون، 🖤 AMOLED (ذخیره می‌شود)
- **آفلاین کامل 📡** + **PWA قابل نصب** (اسمبل‌مانیفست + سرویس‌ورکر؛ offline-first)
- **داده‌های نمونهٔ قابل‌حذف**، خروجی/بازیابی فایل پشتیبان، تأیید قبل از هر حذف، حالت‌های خالی/خطا

## اجرا در محلی

```bash
npm install
npm run dev        # توسعه روی http://localhost:5173
```

## نسخهٔ نهایی (PWA با سرویس‌ورکر)

```bash
npm run build      # خروجی در dist/
npm run preview -- --host 0.0.0.0 --port 4173
```

سرویس‌ورکر در حالت `dev` فعال نیست؛ برای تجربهٔ کامل PWA (نصب + آفلاین) از نسخهٔ build استفاده کن.

## نصب روی گوشی

- **اندروید (Chrome):** منوی ⋮ ← «نصب اپلیکیشن» (یا دکمهٔ «افزودن به صفحهٔ اصلی» در تنظیمات برنامه)
- **آیفون (Safari):** دکمهٔ اشتراک‌گذاری ← «Add to Home Screen»

## ذخیره‌سازی داده

تمام داده‌ها (لیست‌ها، کالاهای من، کالاهای شخصی، تنظیمات و تم) در `localStorage` با کلید `kharidino.v1` و به‌صورت JSON ذخیره می‌شوند. هیچ داده‌ای به سرور نمی‌رود.

## ساختار پروژه

```
index.html            # پوستهٔ HTML (fa / RTL)
vite.config.js        # Vite + vite-plugin-pwa (manifest + workbox)
public/icons/         # آیکون‌های PWA (192/512/maskable/apple)
src/
  main.jsx            # نقطهٔ ورود + فونت وزیرمتن + ثبت SW
  App.jsx             # شل: routing، splash، toast، دیالوگ تأیید
  styles.css          # سیستم طراحی + ۴ تم
  lib/
    catalog.js        # دسته‌بندی‌ها و کالاهای پیش‌فرض
    sample.js         # داده‌های نمونهٔ اولیه
    storage.js        # خواندن/نوشتن localStorage
    utils.js          # ارقام فارسی، زمان نسبی، تطبیق نام
  state/store.jsx     # reducer + context + پایداری + تم + نصب
  components/         # Sheet، BottomNav، Fab، Switch، EmptyState، ...
  screens/            # صفحه‌های لیست‌ها، جزئیات، کالاها، تنظیمات، شیت‌ها
```

## تکنولوژی

React 18 · Vite 5 · vite-plugin-pwa (Workbox) · فونت وزیرمتن (بسته‌بندی‌شده برای آفلاین)
